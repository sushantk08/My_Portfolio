# Sushant Kulkarni — Personal Portfolio

A modern, responsive developer portfolio showcasing backend engineering, AI evaluation, and full-stack projects.

## 🚀 Features

- **Dark Theme UI**: Clean layout built with custom CSS variables and typography from Space Grotesk & Inter.
- **Interactive Project Filtering**: Instant client-side filtering by category (All, Full-Stack, AI / ML, Backend, Data Eng, Tested/CI).
- **Direct Resume Download**: Built-in button to download a PDF resume directly from the assets folder.
- **Dedicated Education & Experience Sections**: Clear separation between academic background and professional software roles.
- **Responsive Navigation**: Mobile slide-out menu drawer and desktop navbar with scrollspy section highlighting.
- **Zero External Dependencies**: Pure HTML5, CSS3, and vanilla JavaScript—no build tools or framework setup required.
